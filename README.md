## 📌 Featured Projects

### 🔹 Leave Management System
Leave Management System using Microsoft Power Apps, designed to streamline employee leave requests and approvals.

👤 Employee View:
Employees can log in to the app and add, edit, or delete their leave request entries. The app is also integrated with Gmail, allowing users to work within their familiar email environment for login or notifications.

👨‍💼 Manager View:
Managers can view all submitted leave requests and update the status to either Approved or Rejected after reviewing the details.

✅ The app is built using Power Fx formulas and connected to SharePoint for data storage. It runs smoothly on both desktop and mobile devices.

💡 A practical example of how Power Apps can automate routine HR processes, enhance visibility, and improve overall efficiency.
